## 项目启动：一键更新 GUI 客户端（Rust 重构）

**背景**：原实现是 `D:\Users\Desktop\一键更新\一键更新.ps1`（21KB，569 行）+ `.bat` 自提权启动器。
功能：npm 全局包（含 dev/beta tag 优选）→ winget → pip → OpenClaw beta（含 gateway 停止/重装）四类源，
支持交互菜单 / -AutoUpdate / -CheckOnly 三种模式。

**目标**：用 Rust 重构成可视化 GUI 客户端（非 CLI）。

### 技术选型（用户确认）
- GUI 技术栈：**Tauri v2 + Vite + 原生 TypeScript**（无前端框架，手写 CSS）
- 功能范围：1:1 复刻四类源 + 逐项勾选增强
- 产出：单文件绿色 exe + NSIS 安装包（两者都要）

### 关键环境约束
- Tauri v2 在 Windows 上**硬性要求 MSVC 工具链 + VS Build Tools**，不支持 windows-gnu
- 用户原环境只有 `stable-x86_64-pc-windows-gnu`，无 VS Build Tools
- 已补装：`rustup toolchain install stable-x86_64-pc-windows-msvc`（rustc 1.98.1）
- winget 装 VS Build Tools **假成功**（只装了 Installer，vswhere 查无实例）→ 用户手动安装到 `D:\Program Files\Microsoft Visual Studio`
- WebView2 Runtime 152.0.4191.66 已存在
- Node v22.22.2 < openclaw 要求的 22.22.3，openclaw 会走跳过分支

### 已产出
- `src-tauri/`：Cargo.toml、build.rs、tauri.conf.json（decorations:false + transparent:true 自绘标题栏）、capabilities/default.json
- `src-tauri/src/`：model.rs / util.rs / lib.rs / main.rs / sources/{npm,winget,pip,openclaw}.rs

### 设计决策
- 不用 tauri-plugin-shell，直接用 `std::process::Command`（cmd /C 包装兼容 npm.cmd），避免 IPC 权限配置
- 子进程输出解码：UTF-8 优先，失败回退 GBK（encoding_rs）
- 日志/进度通过 Tauri event（`update-log` / `update-progress`）流式推给前端
- 版本比较自写宽松算法（数字段优先于非数字段），不引 semver 依赖
